## Synthetic versus live

Synthetic rules/data exercise safety semantics and integration mechanics. They do not demonstrate real-world inference accuracy or live company supply. Live-source observations require explicit source access/spend scope and cannot send real commercial communications during this campaign. No conclusion about deployed state is drawn from repository tests.

## Known-bad witnesses

At minimum reject: capability-as-demand, profile-as-stock, stale approval, unknown-as-zero, incorrect unit, double allocated quantity, missing graph edge, wrong buyer role, forged source, stale revision/tombstone replay, cross-company access, worker impersonation, HTTP200 failure packet, and queued work executing after disable.
