The authoritative owner SHALL enforce the transition and return accepted/refused with reason and provenance; no direct state write or bypass is allowed."

- Basis: **DEFERRED_COVERAGE_DEBT** (no witness test exists yet; carried to the final campaign audit)
- Justification: Gap: no test accepts a booking revision and then asserts that transaction/PO/SO/load/compliance state is unchanged, nor that a permitted transition goes through a named guarded command. partial: test_booking_and_revision.py::TestBookingAndRevision::test_candidate_needs_exact_source_and_changes_nothing_current (a candidate changes nothing current); test_export_owner_handoff.py::TestExportOwnerHandoff::test_export_writes_no_field_on_another_owner_and_has_no_controller (asserts no controllers/ dir); plasticos_logistics/tests/test_linda_freight_models.py::TestLindaFreightModels::test_load_provenance_and_state_bypass_is_rejected and plasticos_logistics/tests/test_load_cardinality.py::TestLoadSourceCompanyAndPhysicalEvents::test_dispatch_state_cannot_be_written_around_the_guard (direct state writes refused).
