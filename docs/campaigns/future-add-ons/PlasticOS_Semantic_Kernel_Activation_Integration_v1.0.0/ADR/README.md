These descriptive names deliberately do not allocate numeric ADR IDs. At adoption, each owner chooses an unused final identifier and updates exact references. Numeric prefixes are not enough: the Odoo repository already contains distinct ADRs sharing numbers.

`AMENDMENTS.md` contains precise insertions and narrow supersessions for existing ADRs. It also names unchanged constraints. No blanket rewrite of constitutional law or historical BRS is authorized. `ADR_REGISTER.json` maps each change to its effect and proof.
