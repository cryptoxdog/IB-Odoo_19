# Operator brief: Semantic Kernel activation program

**Decision locked:** keep and fully develop industrial supply/demand intelligence. **Operating state:** dormant until fixed, connected, tested and separately activated.

## What it is being developed to do

EIE will derive source-backed hypotheses about likely material consumption and generated scrap. Verified source records will represent actual supply and confirmed buyer requirements. CEG will match them and distinguish scoped shortages, unmatched supply and information gaps. Odoo will show evidence and support explicit qualification into the existing native CRM workflow.

A hypothesis is never stock. Capability is never confirmed purchasing intent. A material profile is never a current load by itself. All commercial matching/offers remain opportunity-owned; Won remains confirmed PO issuance.

## Most important implementation choices

Reuse existing partnerless CRM facility/material ownership. Retain semantic concepts but remove their independent commercial workflow. Reuse generic inference, transport and admission mechanisms where already adequate. The proposed optional integration bridge requires a necessity/admission check before any scaffold; it is not a blanket instruction to create another layer.

The backfill writer, real call-site dormancy, graph nodes AND relations, live contract parity, source-state freshness and canonical result identity must all be proven. Removing a blocked-family constant does not achieve any of those outcomes.
