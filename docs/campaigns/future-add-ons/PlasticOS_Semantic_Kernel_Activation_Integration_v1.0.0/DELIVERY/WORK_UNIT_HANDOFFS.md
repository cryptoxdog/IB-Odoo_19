# Bounded implementation handoff policy

This document is not a dispatched coding contract and grants no repository writes. Before delegation, refresh the exact sources, resolve the material frontiers, accept the unit's frozen interface and obtain explicit authorization. The coding-agent contract must enumerate all read-only and writable repositories and only the necessary paths.

## Agent loading routes

- **Odoo planner/runtime operator:** README, case.json, FRONTIERS, DATA_CONTRACT, MIGRATION_AND_RECOVERY, U00/U01 and actual repository instruction owners.
- **Odoo implementer:** one assigned O02-O18 effect group, its direct prerequisites and tests; the optional bridge proposal only after F05 admission. Do not ingest every external repo.
- **EIE implementer:** SK-A02, X01-X02, INFERENCE_AND_GAP_SPEC and the frozen relevant wire/source contract.
- **CEG implementer:** SK-A03, X03-X05, DATA_CONTRACT and gap/matching proof cases. Preserve domain neutrality.
- **Gate implementer:** X06, exact accepted actions/caller scopes, W07-W09 and security tests. No industrial business logic in Gate.
- **Independent reviewer:** exact final diffs, immutable sources, effect/proof ledger and negative cases; not author claims alone.

## Velocity and scope controls

One agent owns one bounded unit and one writable repository. Publish only through the currently verified governed publication owner after separate authorization; this pack does not assert an executable `make` target exists in a consumer repository. No merge/deploy from an implementation grant unless expressly included.

Start with an outcome and allowed paths. File additions are limited to the ledger, subject to the owner sufficiency test. Do not generate generic registries, plugin systems, message buses, local intelligence or speculative UI frameworks. If a necessary new file/interface is discovered, record the counterexample, revise the affected plan and obtain the expanded grant before writing it.

Require a finite diff estimate at unit start and compare actual effects before publication. Arbitrary line-count targets do not override correctness, but a growing diff requires explanation against current obligations. Do not create a 10,000-line rewrite to avoid one contract correction. Tests must not be weakened or marked skipped to obtain a pass.

## Required handoff back

Exact repository/head/base, changed paths, source contract versions, executed commands from verified owners, actual stdout/receipts, positive/negative proofs, schema/migration/ACL changes, remaining findings with disposition, and next prerequisite. State no merge/deploy/activation occurred when none was authorized. No invented green results.

## Cross-campaign boundary

Native Web Lead -> Opportunity, partnerless material matching, canonical buyer selection, offer mail draft approval and confirmed-PO/Lost lifecycle stay owned by the branched commercial campaign. This kernel consumes an exact tested interface and may report a blocker to that owner; it does not repair or republish their PR under this authorization. Reuse accepted work rather than solving it twice.
